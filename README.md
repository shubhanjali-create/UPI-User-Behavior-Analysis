# UPI Favouritism: Data Analysis on User Preference

A data analysis project exploring general UPI (Unified Payments Interface) usage habits in India, based on a self-collected survey.

## Overview

UPI has become the dominant mode of digital payment in India, with multiple apps -PhonePe, Google Pay, Paytm, BHIM, and others -competing for everyday use. This project studies general UPI usage habits among users to understand patterns of preference across different apps.

## Objective

To analyze survey data on UPI usage habits and understand user preference patterns among different UPI apps.

## Data Source

Primary data collected through a self-administered survey on general UPI usage habits.

## Tools Used

- Microsoft Excel
- Power BI
